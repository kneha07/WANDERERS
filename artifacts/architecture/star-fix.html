Problem
The night module is shallow: the page must call five functions in the right order, and the rules between them (used or not, map span, list open) live in the DOM file with no test.
Evidence
b62b108 changed the map span rule inside starfix.js; no test caught or now holds it. isUsed() repeats the outlier rule of night(). headline() takes six positional arguments, so its interface is nearly as wide as its implementation.
Solution
Let night(rows, {cities, example}) return everything one answer block shows. fill() becomes DOM writes and the canvas draw.
Wins
  • locality: block rules in one module
  • leverage: example and real nights, one call
  • map span rule gets a test
  • delete isUsed duplicate
  • tests cross one interface
Deletion test
Delete headline() today: its complexity moves into fill(), not away. So the logic earns its keep, but the seam sits one level too low.
Cost
About 40 lines move from starfix.js to starfixcore.js. Existing headline and describe tests can stay. Update the §8 table in the spec.

After: HTTP adapter over a deep solver module

HTTP adapter: busy, body limit, reply
solvePhoto(buf, {python, timeoutMs}) → {code, body} spawn · stdin · timeout + kill tree · parse · classify the 500s later: a warm worker behind the same interface (#58)
Problem
Process control leaks into the route: the 60 s limit, the kill tree and the error words have no seam, so tests must start a whole server and cannot reach the 504.
Solution
Move starFix() to a module that returns a promise of {code, body} and takes the Python path and the time limit. The route stays an HTTP adapter.
Wins
  • 504 testable in milliseconds
  • locality: one place for process rules
  • warm worker swap stays local
  • drop the source-regex test (A9)
Why not Strong
Today one adapter sits behind the seam (cold spawn), so the seam is hypothetical. It becomes real when the #58 warm-worker item starts. Do it then, as the first step of that work.
Structural link to #58: the "60 s kill has no test" and "one warm worker process" items both depend on this seam.
